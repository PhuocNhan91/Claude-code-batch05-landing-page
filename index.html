Chương Trình 8 Buổi

Lộ trình được thiết kế tối ưu hóa thời gian, tập trung vào kỹ năng thực chiến.

1

Làm quen Claude Code

Cài đặt, cấu hình môi trường phát triển & luồng làm việc cơ bản (Workflow) với AI.

2

Prompt Engineering thực chiến

Nghệ thuật giao tiếp với Claude Code: Cách viết prompt chuẩn xác để AI sinh ra code đúng ý đồ kiến trúc.

3

Thiết kế kiến trúc ứng dụng cùng AI

Phân tích yêu cầu bài toán (ProjectOS), lên ý tưởng Database Schema và thiết kế System Architecture.

4

Xây dựng Backend với Firebase

Thiết lập Firebase Auth, Firestore Database, và viết các rules bảo mật cơ bản với sự trợ giúp của AI.

5

Xây dựng Frontend — UI & Xử lý nghiệp vụ

Tạo giao diện người dùng bằng Next.js + TailwindCSS, kết nối với Firebase và xử lý các thao tác CRUD dữ liệu.

6

Debug & Refactor cùng AI

Kỹ năng tìm và sửa lỗi nhanh chóng. Dùng AI để tối ưu hóa code (clean code) và cải thiện hiệu năng.

7

Tích hợp tính năng nâng cao

Thêm biểu đồ thống kê, xuất file Excel/PDF, phân quyền người dùng phức tạp trong ProjectOS.

8

Deploy & Hoàn thiện sản phẩm trên Vercel

Cấu hình CI/CD, deploy ứng dụng Next.js lên Vercel. Tổng kết khóa học và định hướng con đường phát triển tiếp theo.
